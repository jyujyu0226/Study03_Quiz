# 상식 퀴즈

브라우저에서 바로 풀 수 있는 상식 퀴즈 게임입니다. 카테고리(한국사, 세계지리, 과학, 예술과 문화)를 고르고 모드(연습, 스피드, 힌트)를 골라 한 판(10문제)을 풉니다.

- 요구사항: [PRD.md](PRD.md)
- 구현 계획: [IMPL-PLAN.md](IMPL-PLAN.md)
- 작업 지침과 문항 작성 규칙: [CLAUDE.md](CLAUDE.md)

## 실행

`index.html`을 브라우저로 열면 됩니다.

## 점검

```
node check.js
```

마지막 줄이 `통과 N, 실패 0`이면 문항 데이터와 규칙 로직이 맞습니다.
